# Screen Notes - Vertical Feed MVP

## Screen 1 - Organic editorial video
Purpose:
Show the main feed experience.

Must include:
- full-screen vertical video
- minimal top label or feed context
- right-side action rail
- bottom metadata block
- visible captions/subtitles
- sound toggle
- immersive dark UI

Notes:
- This is the hero state
- It should feel highly engaging and content-first
- UI should not feel cluttered
- Editorial trust should come through in publisher name / metadata treatment

## Screen 2 - Sponsored in-feed video
Purpose:
Show how monetised video content appears naturally inside the feed.

Must include:
- same overall feed structure as organic state
- clear Sponsored label
- CTA button or link
- same action rail positioning
- same metadata hierarchy where appropriate

Notes:
- Sponsored content should feel native, not like a banner interruption
- It should still feel premium and scrollable
- The difference between editorial and sponsored must be obvious but not visually jarring

## Screen 3 - Organic video with overlay ad
Purpose:
Show a lower-third advertising / promo treatment on top of editorial video.

Must include:
- organic editorial video as base state
- lower-area overlay ad or promo unit
- clickable CTA
- captions still readable
- metadata still readable
- overlay should not dominate the screen

Notes:
- This is an important monetisation concept for stakeholder discussion
- The ad should feel integrated, not annoying
- Placement should avoid conflict with subtitles and key video content

## Optional variation - Organic video with sound on
Purpose:
Show a slightly more explicit playback state if needed.

May include:
- sound-on icon state
- subtle progress indicator
- stronger caption hierarchy if useful

Notes:
- Only include if it helps explain behaviour
- Do not turn this into a separate major flow
